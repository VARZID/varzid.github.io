# VARZID SCORE

Платформаи футболи маҳаллии Фархор.

## Файлҳо

- index.html — сохтори сайт
- style.css — дизайн ва намуди равшан/торик
- app.js — кори интерфейс ва танзимоти забон
- supabase.sql — сохтори ибтидоии база
- README.md — дастури лоиҳа

## Гурӯҳҳо

1. Гурӯҳи олии Фархор
2. Гурӯҳи шаҳрак
3. Гурӯҳи Деҳ Шарқ
4. Гурӯҳи Деҳ Ғарб
5. Гурӯҳи Деҳ Шимол
6. Гурӯҳи Деҳ Ҷануб

## Администраторҳо

- Асосӣ админ — идоракунии ҳамаи гурӯҳҳо.
- 5 админи гурӯҳӣ — ҳар кадом танҳо гурӯҳи худро идора мекунад.

## Вазъи ҳозира

Ин прототип аст. Забон ва мавзӯъ дар браузер нигоҳ дошта мешаванд. Бозиҳо ва дастаҳо намунавӣ ҳастанд. Воридшавии админ, базаи зинда ва ҳисобкунии автоматии рейтинг ҳанӯз пайваст нашудаанд.

## Насб

Ҳамаи панҷ файлро ба як папкаи GitHub Pages гузоред.

SQL-ро танҳо баъди санҷиш дар Supabase иҷро кунед. Аввалин профили super_admin бояд баъди сохтани Auth user бо UUID-и воқеӣ ва бо тартиби бехатар сабт шавад.

## Муҳим

Рейтинги доимӣ дар база ҷой дорад, аммо ҳисобкунии автоматии он ҳанӯз сохта нашудааст. Натиҷаҳои намунавиро ҳамчун натиҷаи воқеии мусобиқа истифода накунед.
